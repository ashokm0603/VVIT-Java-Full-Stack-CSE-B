Variables : 
----------
    ->Variables are the named memory location used to store data/values and it can change N no. of times during execution 

way to declear Variables 
------------------------
    1. let 
        ->let variable acts like a block scop 
        ->declaration and initialization in same line is possible 
        ->re-declaration is not possible and re-initialization is possible 
        ->we can not hoist "let variables"

    2. var 
        ->let variable acts like a global scop 
        ->declaration and initialization in same line is possible 
        ->re-declaration and re-initialization is possible 
        ->we can hoist "var variables"

    3. const 
        ->let variable acts like a block scop and final 
        ->declaration and initialization in same line is possible 
        ->declaration and initialization in different line is not possible 
        ->re-declaration and re-initialization is not possible 
        ->we can not hoist "const variables"
